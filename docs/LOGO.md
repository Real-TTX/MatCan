# DesignThix – logo and icons

## Concept

The mark is a **"D" shaped like a label**: the straight stem with rounded corners and the round bowl form one tag, with a **punched hole**
at the top left and **two text lines** cut out of its face (a design with placeholders). Flat apart from one diagonal gradient. Hole and
lines are cut-outs (`fill-rule="evenodd"`), so the surface behind shows through – on dark backgrounds the tag looks really punched.
The word mark is **DesignThix** in Poppins SemiBold (SIL OFL 1.1) drawn as **outlined paths** (no font needed, identical everywhere):
"Design" in navy, "Thix" in the blue of the gradient's end.

The gradient runs top left → bottom right. Gradients are identity only: nowhere else in the UI.

## Levels of detail and files

All SVGs live in `src/DesignThix/wwwroot/`, are generated by `tools/logo.js`, have an exact `viewBox`, no external references, no scripts,
no `<style>` and ids prefixed `dtlogo-` (unique per file, so several logos can be inlined on one page).

| Level | File | Size / viewBox | Use |
|---|---|---|---|
| Full logo (light background) | `logo.svg` | 507 × 96 | sign-in, setup, error pages, README, og-image |
| Full logo (dark background) | `logo-dark.svg` | 507 × 96 | same, on dark surfaces |
| Mark only | `logo-mark.svg` | 96 × 96 | menu header, small spaces; works on light and dark |
| Word mark only | `logo-wordmark.svg`, `logo-wordmark-dark.svg` | 391 × 81 | places that already show the mark |
| Favicon | `favicon.svg` | 96 × 96 | browser tab: bigger hole, heavier text lines, readable at 16 px |
| Maskable icon | `img/icon-maskable.svg` | 512 × 512 | full-bleed gradient with a white D (cut-outs show the gradient), inside the 80 % safe zone |

Rasters in `src/DesignThix/wwwroot/img/` (rendered by `tools/icons.js`, committed):

| File | Source | Use |
|---|---|---|
| `favicon-32.png` | `favicon.svg` | fallback favicon, transparent |
| `apple-touch-icon.png` (180) | `icon-maskable.svg` | iOS home screen; opaque, iOS rounds the corners |
| `icon-192.png`, `icon-512.png` | `icon-maskable.svg` | manifest icons, purpose `any`: rounded tile, transparent corners |
| `icon-maskable-192.png`, `icon-maskable-512.png` | `icon-maskable.svg` | manifest icons, purpose `maskable`: full bleed |
| `og-image.png` (1200 × 630) | `logo.svg` + claim | social preview |

## Regenerating

```
cd tests/e2e && npm install && npm install --no-save opentype.js@1 @fontsource/poppins && cd ../..   # once
NODE_PATH=tests/e2e/node_modules node tools/logo.js     # the SVGs
NODE_PATH=tests/e2e/node_modules node tools/icons.js    # the PNGs (Playwright, installed Edge)
```

Change the geometry in `tools/logo.js` (D outline, `DETAIL` = hole and lines of the normal mark, `SMALL` = the heavier favicon variant),
never by hand in the SVGs. Check every change at real size, at 16/32 px, on a light and a dark background.
