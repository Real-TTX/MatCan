# Bundled fonts

DesignThix never loads fonts from the internet. These fonts are shipped with the app and seeded into the font list
(`fonts.json`). All files are the unmodified TTFs of the official Google Fonts repository
(<https://github.com/google/fonts>), only renamed (`Name[wght].ttf` -> `Name-Variable.ttf`, so the file names are safe in URLs).
Variable fonts cover the whole weight range in one file.

| Family | Files | Licence | Source directory |
|---|---|---|---|
| Montserrat | normal, italic (variable 100-900) | SIL OFL 1.1 | `ofl/montserrat` |
| Bebas Neue | regular | SIL OFL 1.1 | `ofl/bebasneue` |
| Oswald | variable 200-700 | SIL OFL 1.1 | `ofl/oswald` |
| Kaushan Script | regular | SIL OFL 1.1 | `ofl/kaushanscript` |
| Caveat | variable 400-700 | SIL OFL 1.1 | `ofl/caveat` |
| Playfair Display | normal, italic (variable 400-900) | SIL OFL 1.1 | `ofl/playfairdisplay` |
| Lora | normal, italic (variable 400-700) | SIL OFL 1.1 | `ofl/lora` |
| Open Sans | normal, italic (variable 300-800, width axis unused) | SIL OFL 1.1 | `ofl/opensans` |
| Roboto Slab | variable 100-900 | **Apache 2.0** (published under `apache/` by Google Fonts) | `apache/robotoslab` |
| Pacifico | regular | SIL OFL 1.1 | `ofl/pacifico` |
| Permanent Marker | regular | **Apache 2.0** (published under `apache/` by Google Fonts) | `apache/permanentmarker` |
| Source Sans 3 | normal, italic (variable 200-900) | SIL OFL 1.1 | `ofl/sourcesans3` |

The licence texts are in `LICENSES/<Family>.txt` and must stay with the fonts. Every font contains the glyphs
`ä ö ü Ä Ö Ü ß €` (checked in the cmap table).

`fonts.json` is generated by `tools/builtin.js`.
