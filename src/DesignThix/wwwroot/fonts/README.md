# Bundled fonts

DesignThix never loads fonts from the internet. These fonts are shipped with the app and seeded into the font list
(`fonts.json`, generated by `tools/builtin.js`). The source of every file is the official Google Fonts repository
(<https://github.com/google/fonts>); each `fonts.json` entry names the upstream file. Variable fonts cover the whole weight range in one file
(`weight` is then a range such as `400 700`; a weight is three digits, so Nunito's 1000 is written as 900). The file names are safe in URLs.

Two kinds of file:

- **TTF, unmodified** (the first twelve families, and every family below that reserves its name): the file of the repository, only renamed
  (`Name[wght].ttf` -> `Name-Variable.ttf`). The SIL OFL counts a changed format as a modification, and a modified version may not use a Reserved
  Font Name, so these families are never converted or subset.
- **WOFF2, subset** (families without a Reserved Font Name): ONE file per face with Basic Latin, Latin-1, Latin Extended-A/B, spacing modifiers,
  combining marks, Latin Extended Additional, general punctuation, super/subscripts and currency signs (the app registers one file per family,
  weight and style and has no unicode-range). Variable axes are kept (Fredoka: width pinned to 100, Inter: optical size pinned to 14, so the text
  measuring of the engine does not depend on the size). The name table with copyright, licence and licence URL is kept. Made by `tools/fonts-subset.js`
  (needs the npm package `subset-font`, not a dependency of the repository) from the files named in the table.

RFN = the licence reserves the font name, so the file is the unmodified TTF. The licence texts are in `LICENSES/<Family-With-Dashes>.txt` and must
stay with the fonts. `node tools/fonts-check.js` checks every font: the glyphs `ä ö ü Ä Ö Ü ß €` (must), the typographic marks `„ " " ‚ ' ' – — … •`
and `é è ñ ç ł ž š ő` (reported), the weight against the file, the licence text; `--sheet out.png` draws a specimen sheet, `--metrics out.json`
measures ascent, descent and digits in Edge. Known gaps: `ő` is missing in Permanent Marker, Fredoka and Gochi Hand.

`fonts.json` is generated by `tools/builtin.js`.
